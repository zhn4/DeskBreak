# DeskBreak

DeskBreak 是一个 Chrome 扩展，用于提醒用户补水、起身活动和进行简单的拉伸练习，帮助减少长时间久坐。

## 功能

- 定时提醒喝水、站立拉伸和提肛训练，可分别启用或停用。
- 支持“全部暂停”和恢复提醒。
- 提醒间隔可选，最短为 10 秒。Chrome 闹钟可能延迟触发，间隔不代表精确到秒的计时保证。
- 浏览器窗口处于前台时，在当前活动网页内显示提醒；窗口不在前台时，使用系统通知。
- 站立拉伸提醒提供“好的”入口，可打开跟练动作说明。
- 设置保存在 Chrome 本地存储中。

默认设置：

| 提醒 | 默认状态 | 默认间隔 |
| --- | --- | --- |
| 喝水 | 开启 | 45 分钟 |
| 站立拉伸 | 开启 | 60 分钟 |
| 提肛训练 | 关闭 | 90 分钟 |

## 环境要求

- Chrome 或兼容的 Chromium 浏览器，支持 Manifest V3。
- Node.js 22（版本见 `.mise.toml`）。
- pnpm 10（版本见 `.mise.toml`）。

## 本地开发

安装依赖并启动 Vite 开发服务器：

```bash
pnpm install
pnpm dev
```

开发模式下，点击“测试提醒”会直接在预览页面显示提醒，不会发送 Chrome 系统通知。

## 构建并加载扩展

```bash
pnpm build
```

构建产物位于 `dist/`。在 Chrome 中加载：

1. 打开 `chrome://extensions`。
2. 开启右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择项目中的 `dist` 目录，而不是项目根目录。

修改代码后重新运行 `pnpm build`，然后在扩展管理页点击扩展的刷新按钮。

## 权限说明

扩展清单位于 `public/manifest.json`，声明了以下权限：

| 权限 | 用途 |
| --- | --- |
| `alarms` | 安排周期提醒 |
| `notifications` | 显示浏览器系统通知 |
| `scripting` | 需要时向当前活动标签页注入提醒脚本 |
| `storage` | 保存提醒设置和暂停状态 |
| `<all_urls>` 主机权限 | 在支持的网页中显示页内提醒 |

## 注意事项

- Chrome 内部页面（例如 `chrome://` 页面）和 Chrome 网上应用店页面不允许扩展注入页内提醒脚本；请在普通网页中测试。
- 系统通知是否显示还受浏览器和操作系统的通知设置影响。
- Chrome 闹钟的触发时间可能受浏览器调度影响；10 秒是可设置的最短间隔，不保证准点触发。

## 项目结构

```text
public/
  manifest.json   # Chrome 扩展清单
  background.js   # 闹钟调度和通知路由
  content.js      # 网页内提醒和拉伸动作弹窗
src/
  App.tsx         # 扩展弹出页
  index.css       # 页面样式
dist/             # pnpm build 生成的扩展目录
```
